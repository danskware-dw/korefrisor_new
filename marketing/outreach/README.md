# Outreach — plejehjem

- `pitch-dansk.md` — telefon, e-mail, opfølgning, printkort
- `maaliste-plejehjem.csv` — starterliste (Tårnby + Dragør + Amager-eksempler)

## Sådan bruger du listen
1. Åbn CSV i Numbers / Excel / Google Sheets.
2. Status: `klar` → ring/mail denne uge · `udforsk` → find telefon først · `tom` → dine egne rækker.
3. Efter hver kontakt: udfyld kontaktperson, sidst_kontakt, næste_skridt, resultat.
4. Mål for uge 1–2: 10 kontakter, 2 pilotbesøg.

## Kilder (tjek før du stoler 100%)
- plejehjemsoversigten.dk / Tårnby Kommune
- dragoer.dk (Enggården)
- boligertilaeldre.kk.dk (KK Amager)

Telefonnumre og boligtal kan ændre sig — bekræft ved første opkald.
